# 🛍️ Local Marketplace

A responsive and interactive **client-side marketplace web application** where users can browse, create, manage, and interact with local listings.

The project was developed to practice modern front-end development concepts including **dynamic DOM manipulation, CRUD operations, role-based functionality, form validation, filtering, and browser-based data persistence.**

---

## ✨ Features

### 🔎 Browse & Discover
- Browse marketplace listings
- Search listings dynamically without page reload
- Filter by category, listing type, and price range
- View detailed information for individual listings

### 👤 Role-Based Access
The application supports three different user roles:

- **Visitor** — Browse, search, filter, and view listings
- **Member** — Create, edit, and delete personal listings, manage favorites, and report listings
- **Moderator** — Review reported listings through the moderator dashboard

### 📝 Listing Management
- Create new listings
- Edit existing listings
- Delete owned listings
- Client-side form validation
- Image URL validation

### ❤️ Favorites & Reports
- Add and remove listings from favorites
- View favorite listings from the dashboard
- Report inappropriate listings
- Moderator view for reported content

### 💾 Data Persistence
Listing data, user roles, favorites, and application state are stored using **LocalStorage**, allowing data to persist between page visits.
